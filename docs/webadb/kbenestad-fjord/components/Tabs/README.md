# Tabs

Two forms: `.seg` (segmented control) and `.tabs` (underlined tabs).

**Consumer provides:** links or buttons; the current one gets `.on`.

- `.seg`: filters within one list (All / Open / Paid). Track is `sunk`, the selected segment lifts to `view`.
- `.tabs`: switching between sections of one record. The active tab is `ink` with a 2px `acc` underline; others `muted`.
- Keep labels to one or two words.
