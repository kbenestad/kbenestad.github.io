Open this page in a Chromium-based browser, such as Brave, Chromium, Edge or Chrome. Firefox and Safari don't support WebUSB.

Connect a phone

Data folder

If you wish to transfer data to/from the phone (including installing APKs), you need to set a data folder. In your chosen folder, the following sub-folders will be created:

  • *profiles*: Contains the profile of each connected phone.
  • *files*: This folder will be mounted as the root for WebADB. Data you wish to transfer to and from your phone will be in this folder (including APKs).

Phone

Enable Developer Options and go to **Settings > About phone** and tap *Build number* seven times.

Then go to **Settings > System > Developer options** and enable *Use Developer options* and then *USB debugging*.

If you have problems connecting to your phone, you can try to tap *Revoke USB debugging authorisations*.

Shell is dangerous

It runs any command on the phone with no undo. A wrong command can erase data or stop the phone from starting. To use it: open Preferences in the sidebar, tick Allow unsafe operations, then come back here.
